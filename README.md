# BetArena

نسخة ويب خفيفة (HTML/CSS/JS بدون أدوات بناء) تشتغل مباشرة على أي متصفح وأي هاتف.

## التشغيل محليًا
افتح ملف `index.html` مباشرة بمتصفح كروم، أو استخدم أي سيرفر بسيط.

## النشر على GitHub Pages (رابط مباشر يشتغل بكل الهواتف)

1. أنشئ مستودع (repository) جديد على GitHub، مثلاً باسم `betarena`.
2. ارفع كل ملفات هذا المجلد إلى المستودع (عبر الموقع مباشرة "Upload files" أو عبر git).
3. من إعدادات المستودع: `Settings` → `Pages`.
4. تحت `Branch` اختر `main` والمجلد `/ (root)` ثم اضغط `Save`.
5. بعد دقيقة أو دقيقتين بيظهر لك رابط بالشكل:
   `https://USERNAME.github.io/betarena/`
6. هذا الرابط يشتغل على أي جوال أو كمبيوتر مباشرة من المتصفح، وممكن المستخدم يضيفه لشاشة هاتفه الرئيسية زي تطبيق عادي (بفضل ملف manifest.json).

## ملاحظة
هذه النسخة تخزن البيانات محليًا بالمتصفح (localStorage) كبديل مؤقت. لاحقًا لما تحتاج بيانات مشتركة بين المستخدمين (محفظة حقيقية، غرف حقيقية، إلخ) نربطها بباك اند حقيقي (Firebase أو Node.js + قاعدة بيانات).
